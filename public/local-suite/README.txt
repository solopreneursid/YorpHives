YorpHives Local Productivity Suite — version 1.0.0

FREE FEATURES
- Quick Text Assistant: clean whitespace, deduplicate lines, change case, extract URLs, count words/characters, copy output.
- Smart Clipboard: explicitly save reusable text snippets, reuse/copy/delete them. It does NOT monitor or read the system clipboard automatically.
- Page Notes & Research Clips: capture the active page title, URL, selected text and a limited page excerpt after you click the capture button; save/search/copy/delete notes.

PRIVACY
- Snippets and notes are stored using chrome.storage.local in this browser profile.
- No account, remote AI, analytics, backend, or network requests are used by this package.
- Page capture runs only after the user clicks the capture button and may fail on browser-internal or restricted pages.
- Do not store passwords, payment card details, or other sensitive secrets.

INSTALL (Chromium desktop)
1. Download the ZIP from the YorpHives Extensions page and extract it.
2. Open chrome://extensions (or the equivalent extensions page in your Chromium browser).
3. Enable Developer mode, choose Load unpacked, and select the extracted YorpHives-Local-Productivity-Suite folder containing manifest.json.
4. Pin the extension if desired. Review requested permissions before use.

This is an original YorpHives-built manual-install package. It is not represented as store-reviewed or store-published.
