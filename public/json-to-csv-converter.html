JSON to CSV Converter

Paste an array of JSON objects to convert its fields into comma-separated values that can be opened in spreadsheet applications.

Supported input

Provide a JSON array containing objects, for example [{"name":"Ada","role":"Developer"}]. The converter builds columns from the combined object keys and quotes CSV cells when needed. Nested values are represented as JSON text.
