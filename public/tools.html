HOW IT WORKS

Simple, local, useful.

  • Choose an image from your device.
  • Enter a width and/or height if you want to resize it.
  • Optionally rotate by 90°, 180° or 270°, or flip horizontally/vertically.
  • Choose JPG, PNG or WebP output and adjust quality.
  • Lower JPG/WebP quality for smaller files; PNG is lossless and JPG removes transparency.
Tip

JPG and WebP are usually smaller for photos. PNG is useful when you need transparency. Converting to JPG removes transparency.

03 / HELP & PRIVACY

PDF & image tool FAQs.

Answers about file handling, compatibility and what the tools can—and cannot—do.

Are YorpHives’s PDF and image tools free?

Yes. All tools on this page are free to use without a YorpHives account. Outputs have no forced YorpHives branding; the watermark tool only adds text you choose.

Are my documents uploaded to YorpHives?

The selected files are processed in your browser and are not uploaded to YorpHives by these tools. The page loads PDF libraries from third-party CDNs, so an internet connection is needed to load those scripts.

Can Extract PDF Text read a scanned document?

It extracts selectable text embedded in a PDF. It does not include OCR, so a scan that contains only page images may produce little or no text.

Can I rotate only one page?

The current rotation tool rotates every page in the selected PDF. Use Extract PDF Pages if you need a separate file containing selected pages.

Will adding a watermark or rotating a PDF preserve digital signatures?

Editing a PDF can invalidate digital signatures and may affect some forms or advanced document features. Keep your original file and verify the output before using it as an official record.

Can I open password-protected PDFs?

Some encrypted or password-protected PDFs may not load in these tools. The tools do not remove password protection or bypass document security.

Does the image editor support transparency?

PNG and WebP can preserve transparency where the browser encoder supports it. Converting an image to JPG places it on a white background because JPG does not support transparency.

Why might a large PDF or image fail?

Processing uses your browser’s memory, device performance and supported file formats. Try a smaller file or lower export scale if a large document runs out of memory.

What does PDF structure optimization do?

It rewrites the PDF structure using compressed object streams and reports the actual output size. It may reduce the file only slightly or can sometimes make it larger; it does not promise a specific compression ratio.

Does image-based PDF compression preserve selectable text?

No. Raster mode turns each page into a JPEG image. The resulting PDF is visual-only: text search/selection, links, forms, accessibility structure, comments, and digital signatures are not preserved. Keep your original and inspect the result before using it as an official document.
