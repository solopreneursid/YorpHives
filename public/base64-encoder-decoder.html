Base64 Encoder & Decoder

Convert text into Base64 or decode a Base64 string into readable text. Useful for debugging API payloads, data snippets and web development.

What is Base64?

Base64 represents binary data using a text-friendly character set. It is commonly used in data URLs, email formats and API workflows, but it does not encrypt or protect confidential information.

This tool converts UTF-8 text in your browser. Do not treat encoded output as secure storage. Browse the YorpHives tools directory for more developer utilities.
