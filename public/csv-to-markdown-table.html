HOW TO USE IT

Get started

  1. 1. Paste CSV data with column names in the first row.
  2. 2. Choose Convert to Markdown to build the table and separator row.
  3. 3. Copy the result into your Markdown document and check multiline values or unusual CSV dialects.
HELPFUL NOTES

Frequently asked questions

Does the first CSV row become the header?

Yes. The first non-empty row is used as the Markdown table header.

Are commas inside quoted cells supported?

Yes. Standard quoted cells and doubled double-quotes are handled. Review unusual delimiters or complex multiline data.

Is my CSV uploaded?

Conversion runs locally in the browser and does not send your pasted CSV to a YorpHives server.
