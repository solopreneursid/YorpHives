YorpHives Tab Tidy — free local-first browser extension

FEATURES
- Search open tabs by title or URL.
- See duplicate URL groups without automatically closing anything.
- Group tab counts by domain.
- Export current-window tab metadata as JSON.
- Close an individual tab only when you click its Close button.

INSTALL (Chrome / Edge / other Chromium browsers)
1. Download the source files from the YorpHives extension package page or copy the tab-tidy folder.
2. Open the browser Extensions page and enable Developer mode.
3. Choose Load unpacked and select the folder containing manifest.json.
4. Pin Tab Tidy and open its popup.

PERMISSIONS & PRIVACY
The tabs permission is required to list tabs in the current window and read tab titles/URLs. Storage is declared for future local preferences; this initial release does not send data to a server. It does not read page contents, browsing history outside the current tab list, cookies, or form fields. No paid API or account required.

LIMITATIONS
This package is a source folder for manual loading, not a store-reviewed listing. Browser-internal pages cannot be managed like ordinary tabs. Review the tab list before closing anything.
