HOW TO USE IT

Get started

  1. 1. Paste a complete URL, a query string beginning with ?, or key=value pairs.
  2. 2. Choose Parse URL to decode query parameter names and values.
  3. 3. Review duplicate keys as separate entries and avoid pasting access tokens or other secrets.
HELPFUL NOTES

Frequently asked questions

Does it preserve parameters that use the same key?

Yes. Repeated query parameters are listed separately in the order they appear.

Does it modify the original URL?

No. It reads the input and displays parsed information; it does not navigate to the URL or send a request to that site.

Is the URL sent to YorpHives?

Parsing runs in your browser. Avoid entering URLs containing private session tokens into any tool if you do not want them visible on your screen.
