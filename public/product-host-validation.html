The WordPress site runs in the embedded Playground frame. Do not enter personal data or real customer content. Test state is temporary unless you choose to save it in Playground.

After the automated checks

  1. Open the embedded WordPress admin and create a disposable test post.
  2. For Content Check, Image Alt Helper, and Link Audit, open the post editor and manually run the corresponding metabox action against sample content.
  3. For Reading Time, place [yorphives_reading_time] in a test post and verify that the front end renders a sensible estimate.
  4. Open Playground’s Dev Tools → Logs if any warning or error appears, and retain the output before changing plugin code.
