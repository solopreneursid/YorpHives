HOW TO USE IT

Get started

  1. 1. Paste valid JSON with an object at the top level.
  2. 2. Choose a root interface name, such as ApiResponse.
  3. 3. Generate the TypeScript, then review optional properties, null values and mixed arrays against real API responses.
HELPFUL NOTES

Frequently asked questions

Does this generate types for every possible API response?

No. It infers types from the sample you provide. Add optional properties and union types where responses can vary.

Is my JSON uploaded?

Conversion runs in your browser. The page does not send the JSON input to a YorpHives server.

Can the input be a JSON array at the top level?

The current tool expects a top-level JSON object so it can generate a named root interface. Wrap the array in an object or adapt the result manually.
