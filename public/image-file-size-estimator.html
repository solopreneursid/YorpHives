HOW TO USE IT

Get started

  1. 1. Enter the image width and height in pixels.
  2. 2. Choose JPEG, WebP or PNG and a quality value where applicable.
  3. 3. Review the estimated size range. Treat it as a planning guide, because image content and encoder settings can change the actual result.
HELPFUL NOTES

Frequently asked questions

How accurate is this estimate?

It is a heuristic, not an encoder. Real file size varies with image detail, color noise, transparency, metadata, chroma subsampling and encoder implementation.

Does PNG use the quality setting?

No. PNG is lossless and its resulting size is influenced by content and compression implementation; the quality slider is not used for PNG.

Will it compress my image?

No. This tool estimates output size from dimensions and assumptions; it does not open, upload, export or compress an image.
