01 / WHAT IT DOES

A small set of useful actions.

QuickPanel is intentionally focused: quick actions for the page you choose, with the records saved only in your browser profile.

⌘

Selected-text actions

Capture selected text and trim lines, remove duplicates, change case, extract URLs or copy the result.

▤

Page capture

Capture a readable text excerpt, page title and URL from the active tab. Save the page for later reference.

▦

Table extraction

Read the first HTML table on the current page and convert its rows to tab-separated text.

☷

Reading-style toggle

Apply a removable high-readability style to the current page. Some sites may not display perfectly.

✎

Reusable snippets

Keep text blocks in local extension storage and load them into the editor when needed.

⇥

Form assistance

Fill supported blank fields from your profile only after you request it. It never submits the form.

02 / INSTALL

Install the extension yourself.

This first version is distributed as an unpacked development extension. It has not been presented as store-reviewed. Use it only in a browser where you are allowed to install developer extensions.

  1. Press Download QuickPanel ZIP. The ZIP is generated in your browser from the YorpHives source files.
  2. Extract YorpHives-QuickPanel.zip into a folder.
  3. Open your browser Extensions page and turn on Developer mode.
  4. Choose Load unpacked and select the extracted folder containing manifest.json.
  5. Open an ordinary webpage, click QuickPanel, and try a user-invoked action.

The archive is assembled locally; no ZIP service is used.

Permission notes

activeTab
Allows page actions for the tab you choose when you open QuickPanel.
scripting
Runs selected text, page capture, table, reader and form actions you click.
storage
Saves snippets, pages and an optional profile on the current browser profile.
The extension does not request access to all websites by default, does not include a remote AI model, and does not submit forms. Form matching is heuristic, so review every filled field.
03 / FIREFOX FOR ANDROID

QuickPanel for Firefox.

A separate Firefox WebExtension package is prepared for Android and desktop Firefox. It uses Firefox’s browser API namespace, declares Android compatibility, and has a touch-friendly popup. The downloaded ZIP is an AMO submission package—not an installable mobile add-on until Mozilla signing/distribution is completed.

Mozilla Add-ons Developer Hub ↗

Package contains the Firefox manifest and extension source. It has not yet been signed or reviewed by Mozilla.

To install on Firefox for Android, upload the downloaded ZIP through Mozilla’s Add-ons Developer Hub, complete any validation/review steps and obtain a signed add-on. Then install from its Mozilla Add-ons listing. A ZIP download by itself cannot be installed directly from the Firefox Android Add-ons catalogue.

Choose distracting domains and temporarily block top-level navigation during a timed focus session. Review its broad host permission before installing.

05 / QUICK ANSWERS

QuickPanel FAQs.

Is QuickPanel completely free to use?

Yes. The extension package is free and its core actions do not require subscriptions, hosted AI services, or an account. Browser-store publication, if pursued later, may have separate platform requirements or fees.

Which browsers are supported?

The desktop extension ZIP is built for Chromium-based browsers supporting Manifest V3. A separate Firefox edition is prepared for Firefox for Android and Firefox desktop but still needs Mozilla distribution/signing before general installation. Distribution policies vary, and some managed devices may block unpacked extensions.

What can the extension read?

When you open QuickPanel, it can work on the active tab after permission is granted. Actions read selected text, visible page text or the first table only when you invoke them.

Does it send my information to YorpHives?

No network API calls are part of this version. Saved items and optional profile fields are stored in the browser extension storage on your device profile.

Will form filling work on every website?

No. Websites use different field labels and controls. QuickPanel skips password and hidden fields, does not submit forms, and requires you to check every filled field.

Can it fill passwords, payment cards or submit forms?

No. It deliberately skips password, hidden, file, checkbox, radio, disabled and read-only fields. It does not click Submit or send a form for you.

Why does reader styling look odd on some pages?

Websites use different layouts and embedded interfaces. The reader toggle applies a reversible stylesheet, not a full content-removal reader engine. Click the toggle again to remove it.

Can I use QuickPanel on my phone?

The QuickPanel web app works in mobile browsers. A separate Firefox extension package has been prepared for Firefox for Android, but it is not yet signed or published through Mozilla. The original extension ZIP remains for compatible desktop Chromium browsers.

How do I uninstall QuickPanel?

Open your browser extension manager and remove YorpHives QuickPanel. To remove saved extension data, clear its stored data in the browser or remove the extension as directed by the browser.

Is the extension reviewed by the browser store?

No. This release is provided for manual developer-mode installation. It has not been represented as store-reviewed or store-published.
