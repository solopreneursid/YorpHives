03 / FREQUENTLY ASKED QUESTIONS

Workbench FAQs.

Are all YorpHives Workbench tools free?

Yes. The current modules are available without subscription, paid API key, or YorpHives account. Optional publishing and browser-store fees are separate from using this website.

Where is my data stored?

Saved records are stored in local storage within your current browser profile. They are not synced between devices in this version. Export important records before clearing site data or switching browsers.

Does it upload my files or notes?

The Workbench's text and file transformations run in the browser. It does not send the content to an AI provider. The site itself still needs an internet connection to load.

Are the agents powered by artificial intelligence?

The current agents are deterministic helpers. They apply rules, compare text, organise user-provided sources, build checklists and calculate amounts; they do not independently verify facts or browse search engines.

Can the Web Clipper read any page automatically?

This web page cannot read another tab or a different website's DOM. Paste content into the Workbench or use the YorpHives QuickPanel extension on a page you choose.

Does Page Change Tracker monitor a website automatically?

No. It stores a text snapshot when you click Save snapshot and compares it with a later text sample you supply. It does not perform background crawling or server notifications.

Can I sync my notes and jobs across devices?

Cloud sync is not included because the goal is to keep this version free and local-first. Use module export/import options to move records when available.

What is required to use the browser extension?

Download the YorpHives QuickPanel package, extract it, and load its folder as an unpacked extension in a compatible Chromium browser. The initial version uses browser permissions only for actions you invoke.

Can I use the Workbench offline?

After the page assets have loaded, many module actions work locally. Full offline availability is not guaranteed on the first visit, and browser storage remains tied to the current browser profile.

Can I suggest a new module?

Yes. Use the YorpHives project enquiry form to describe the task, who needs it, and why existing workflows are inconvenient.

What does CopyGuard detect?

CopyGuard checks pasted text for common email, phone, token-like key-value patterns and private-key markers locally. It is a heuristic helper, not a security audit; it can miss sensitive data and produce false positives.

Does Webpage Outline visit or scrape a URL?

No. Paste HTML you are allowed to use and it extracts heading text locally. It does not fetch a webpage, access other tabs, or verify that links work.

How does Study Card Maker format flashcards?

Enter one card per line using Question :: Answer. The tool creates a preview and lets you download a CSV file. It does not generate answers with AI.

Does Vocabulary Catcher use an AI dictionary?

No. Add the definitions and example sentences you want to learn. Words are saved in this browser and can be exported as JSON; they are not automatically synced across devices.

Does Source Collector verify citations?

No. It formats the title, URL, access date and notes you provide. Confirm the source exists, supports your claims and follows the citation style required for your work.

Is the Accessibility Helper a full accessibility audit?

No. It checks pasted HTML for a few common issues, such as missing image alt attributes and labels. It cannot assess contrast, keyboard interaction or full WCAG conformance; test the actual page and use a comprehensive audit process.
