YorpHives QUICKPANEL — VERSION 1.0.0

WHAT IT DOES
- Captures selected text from the active tab.
- Captures readable text from a page you choose.
- Saves a page title, URL and short excerpt locally.
- Extracts the first HTML table from the active page as TSV.
- Applies a reading-style overlay to the active page (toggle to remove).
- Applies text cleanup, deduplication, case conversion and URL extraction.
- Stores reusable snippets and an optional profile locally.
- Fills supported empty form fields only after you click the action.
- Does not submit forms, fill passwords, call an AI service or send user content to a YorpHives server.

INSTALL IN A CHROMIUM BROWSER
1. Download and extract YorpHives-QuickPanel.zip.
2. Open the browser's Extensions page.
3. Enable Developer mode.
4. Choose Load unpacked and select the extracted YorpHives-QuickPanel folder containing manifest.json.
5. Pin QuickPanel if you want faster access.
6. Open a webpage and click the extension.

PERMISSIONS
- activeTab: works with the tab where you explicitly open the extension.
- scripting: runs the text/page actions you invoke on that tab.
- storage: saves snippets, saved pages and your optional profile locally.

PRIVACY NOTES
The extension is a local-first prototype. Browser extension storage remains on that browser profile and is not cloud-synced. Back up important snippets or profile data separately. The extension uses label and field-name heuristics for form filling; review all values before submitting. Page layouts vary, so extraction and form filling are not guaranteed on every website.

NO HOSTED AI / NO REQUIRED ACCOUNT
This version does not require a hosted AI API, remote database, subscription or YorpHives account. Publishing through a store may have separate store-specific requirements or fees.
