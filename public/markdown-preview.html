  2. 2. Select Render preview to refresh the preview panel.
  3. 3. Copy the rendered-status note or keep editing; the preview updates when you run it again.
HELPFUL NOTES

Frequently asked questions

Which Markdown syntax is supported?

The preview supports headings up to level three, paragraphs, bullet lists, bold, italic and inline code. It is a lightweight subset rather than a complete CommonMark implementation.

Can raw HTML run in the preview?

No. Text is escaped before basic formatting is added, and the preview is placed in a sandboxed iframe.

Does the tool send my Markdown to a server?

The preview is generated locally in your browser. No server conversion is used.
