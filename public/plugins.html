01 / WORDPRESS

YorpHives Content Check

Free · v1.0.0
✓WORDPRESS PLUGIN

Editorial checklist for posts and pages

Checks title length, rough word count, excerpt, subheadings, links and image alt attributes from the WordPress editor. It does not upload draft content or call external services.

  • WordPress 6.0+
  • PHP 7.4+
  • GPL-2.0-or-later

The installable ZIP is assembled locally in your browser.

Install

  1. Download the ZIP.
  2. In WordPress, open Plugins → Add New Plugin → Upload Plugin.
  3. Choose the ZIP, install and activate it.
  4. Edit a post or page and run the YorpHives Content Check panel.

Checks are advisory heuristics, not a guarantee of SEO ranking, accessibility compliance or editorial quality.

02 / VISUAL STUDIO CODE

YorpHives Developer Toolkit

Free · v1.0.0
{ }VS CODE EXTENSION SOURCE

Four local developer commands

Format JSON, decode URL components, view text statistics and convert selected text to camelCase directly inside VS Code.

  • VS Code 1.80+
  • No external dependencies or network calls
  • MIT license

Source ZIP; not a signed VSIX or Marketplace release.

Use

  1. Download and extract the source ZIP.
  2. For a standard installation, package the folder as a VSIX with Microsoft's VS Code Extension Manager (`vsce`), then install the VSIX in VS Code.
  3. Alternatively, place the folder in your local VS Code extensions directory for development and reload the window.
  4. Open the Command Palette and run a command beginning with “YorpHives:”.

The package is original source code. It is not yet published to the Visual Studio Marketplace, and this page does not claim otherwise.
