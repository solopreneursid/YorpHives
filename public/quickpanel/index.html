Install on your device

Use the browser's Install or Add to Home Screen option to launch QuickPanel like an app.

If no install button appears, this browser may use its own menu, or may not support PWA installation.

⌫

Delete local data

Remove all QuickPanel snippets, clips and profile values from this browser.

Local by default

Text actions, table conversion and saved records run in this browser. There is no required account or cloud sync.

Offline shell

After first loading while online, the QuickPanel app shell and core tools can open offline. Website content and new links still require connectivity.

Moving devices

Export a backup on the old device and import it on the new one. Automatic cross-device sync is not included in this phase.
