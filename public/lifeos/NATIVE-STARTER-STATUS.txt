LifeOS Native Starter — Phase 1 progress
Updated: 2026-10-27
Parent product: YorpHives / LifeOS
Status: source scaffold prepared separately; not yet compiled or tested with Flutter.

WHAT EXISTS IN THE STARTER SCAFFOLD
- Flutter/Dart app shell with Today, Tasks, Habits and Goals navigation.
- Local SQLite database, initial schema and indexes.
- Shared LifeItem model and repository boundary.
- Basic create/list/complete/delete flow for local items.
- Initial model tests and build/test instructions.
- No accounts, cloud sync, telemetry, paid database or server dependency.

COST-CONTROL DECISIONS
- One Flutter codebase for Android first, then other platforms after validation.
- SQLite remains the native local source of truth.
- Keep business/data logic behind repository interfaces; keep platform UI separate.
- Do not introduce accounts, hosted sync, analytics or extra packages until a concrete requirement justifies their maintenance cost.
- Avoid multiple app-specific databases or separate platform implementations.
