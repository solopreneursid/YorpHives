LifeOS — YorpHives early-access prototype
Route: /lifeos/
Distribution: website + installable Progressive Web App (PWA) on compatible browsers.

MVP: tasks with due dates and priorities; habits with daily check-in history; goals with progress and optional next milestone; manual expenses/subscriptions; study/career items, reminders and document references; JSON backup import/export; browser local storage; PWA manifest, 192/512 app icons, scoped service worker and shell caching.

Limits: no accounts/cloud sync, no encrypted server-side storage, no bank connection, no file upload, no connected AI planner. Avoid highly sensitive personal information in this prototype. Installation depends on browser/device; use the browser menu's Install/Add to Home Screen if no prompt appears. This is an installable web app, not a native APK or app-store package.
