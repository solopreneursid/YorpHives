A local editorial checklist for WordPress posts and pages. Checks title presence/length, rough word count, excerpt, subheadings, links and image alt attributes.

== Installation ==
1. Upload the yorphives-content-check folder to /wp-content/plugins/, or install the ZIP through Plugins > Add New Plugin > Upload Plugin.
2. Activate YorpHives Content Check.
3. Edit a post or page and use the YorpHives Content Check panel.

== Privacy ==
Checks run in the WordPress editor in your browser. The plugin does not call external APIs, use analytics, or send draft content to YorpHives. Checks are heuristic and advisory only.
