=== YorpHives Link Audit ===
Contributors: yorphives
Tags: links, editorial, accessibility, security
Requires at least: 6.0
Requires PHP: 7.4
Stable tag: 1.0.0
License: GPLv2 or later

Audits links in the current post/page draft for missing labels, empty or placeholder destinations, and target=_blank links missing rel=noopener. No external services are called and content is not changed.

== Installation ==
Upload the ZIP through Plugins > Add New Plugin > Upload Plugin, install and activate. Open a post or page and use the YorpHives Link Audit box.

== Notes ==
Checks are heuristic and may not understand every valid link pattern. Review findings manually.
