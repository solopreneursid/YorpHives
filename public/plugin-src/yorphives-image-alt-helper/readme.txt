=== YorpHives Image Alt Helper ===
Contributors: yorphives

Requires at least: 6.0
Requires PHP: 7.4
Stable tag: 1.0.0
License: GPLv2 or later

Reviews image alt attributes in the current WordPress post/page editor content. It does not generate alt text, modify content, or send data externally.

== Installation ==
Upload the ZIP through Plugins > Add New Plugin > Upload Plugin, install, and activate. Open a post/page editor and use the YorpHives Image Alt Helper box.

== Notes ==
An empty alt attribute can be correct for decorative images. This is a manual review aid, not an accessibility certification.
