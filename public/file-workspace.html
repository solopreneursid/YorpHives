QUICK ANSWERS

About the file workspace

Are my files uploaded?

No. These operations use browser APIs and the PDF library hosted by YorpHives. Your chosen files are not sent to a YorpHives processing server.

Can it convert every format Filee supports?

No. This web workspace focuses on common image and PDF workflows. Audio, video, office documents, specialist formats, watched folders and command-line automation require additional engines or a desktop app and are not included here.

Where are presets stored?

Presets are stored in this browser's local storage on this device. They are not synced across browsers or devices.
