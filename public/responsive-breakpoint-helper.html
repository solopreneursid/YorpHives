  2. 2. Choose Generate responsive CSS.
  3. 3. Copy the CSS template and test your layout at real viewport sizes rather than relying only on device labels.
HELPFUL NOTES

Frequently asked questions

Are these universal device widths?

No. The default widths are starter values only. Breakpoints should follow the needs of your content and layout, not a fixed list of device models.

Does this create a complete responsive stylesheet?

No. It generates media-query wrappers with comment placeholders. Add the actual layout declarations inside each block.

Can I change the breakpoints?

Yes. Enter your own increasing whole-number widths before generating the CSS.
