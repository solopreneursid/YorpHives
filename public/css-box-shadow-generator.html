HELPFUL NOTES

Frequently asked questions

What do the shadow values mean?

Horizontal and vertical offsets move the shadow, blur softens its edge, and spread expands or contracts it. Inset draws the shadow inside the element.

Can I use multiple shadows?

This version generates one shadow at a time. CSS supports multiple comma-separated shadows, which you can combine manually.

Does the preview modify my website?

No. The shadow appears only in the preview box on this page. Copy the CSS into your own stylesheet when you are ready.
