HELPFUL NOTES

Frequently asked questions

Which entities are included?

The reference covers common punctuation, symbols and HTML-sensitive characters. It is a practical starter list, not an exhaustive Unicode catalogue.

Should I encode every character?

Usually only characters that need escaping in the output context should be encoded. HTML text, attribute values, URLs and JavaScript have different escaping rules.

Is this the same as sanitizing HTML?

No. Entity encoding is not a complete HTML sanitization strategy. Use context-appropriate escaping and safe DOM APIs when building applications.
